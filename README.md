# FreshCrops Store

Production-oriented Next.js catalog and persistent guest cart migrated from the supplied HTML prototype.

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`. Copy `.env.example` to `.env.local` and set the WhatsApp number; without it, order inquiries use email.

## Verify

```bash
pnpm test
pnpm lint
pnpm build
```
